# Responsive Personal Portfolio Website

A clean, responsive personal portfolio built with **HTML5, CSS3, and vanilla JavaScript**. It introduces the developer, highlights skills and projects, presents education/experience, and provides a validated contact form.

## Features

- Responsive layout for desktop, tablet, and mobile
- Semantic HTML5 sections and accessible navigation labels
- Mobile navigation menu with open/close state
- Home, About, Skills, Projects, Education/Experience, and Contact sections
- Contact form validation (name, email, and message)
- Contact form prepares an email using the visitor's default email application
- Reduced-motion preference support
- No framework or build step required

## Run locally

1. Download or clone this project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the **Live Server** extension.
4. Resize the browser or use developer tools to test mobile and tablet layouts.

## Customize before publishing

Search `index.html` and update:
- Name, introduction, location, and career objective
- College, degree, graduation year, CGPA, and internship dates
- Skill list and project descriptions
- Email, LinkedIn, and LeetCode URLs
- Project links when you have public repositories or live demos

The current project descriptions are starter content. Keep only details that accurately describe work you have completed.

## Contact form note

The form validates input in the browser and opens a `mailto:` link. It does **not** send messages to a server or store visitor data. For production use, connect a secure backend or a form service and add spam protection and a privacy notice.
