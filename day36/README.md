# Veda Technology — Business & Services Website

A responsive multi-section company-profile website concept built with HTML5, CSS3, and vanilla JavaScript.

## Website sections

- Home / company introduction
- About Veda
- Technology programs
- IT and digital services
- Internship and training
- Frequently asked questions
- Contact enquiry form

## Features

- Responsive desktop, tablet, and mobile layouts
- Mobile navigation menu
- Semantic HTML5 structure
- CSS Grid, Flexbox, and media queries
- FAQ accordions using native HTML `details` and `summary`
- Client-side contact form validation
- Accessible labels and live status messages
- No framework or build tools required

## Run locally

1. Download and extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Test the navigation, FAQ items, form validation, and responsive layout.

## Important before publishing

This is a frontend demonstration/company-profile concept. It intentionally avoids inventing company-specific facts. Before publishing:
- Replace the placeholder official email in `script.js`.
- Add verified company phone number, address, office hours, and official social links.
- Confirm the exact list of services, technology programs, internship terms, and FAQs with Veda Technology.
- Add approved logo, images, privacy policy, and legal details if required.
- Connect a secure backend or approved form provider if enquiries must be submitted online.

The contact form currently validates input in the browser. Until an official email is configured, it displays a message instead of sending or storing user data.
