# Simple Resume Website

**Veda Technology Internship | Level 1 | Task 3 | Web Development Track**

A single-page online resume built with semantic HTML5 and CSS3. It presents profile, education, skills, experience, projects and contact information in a clean, responsive two-column layout that is easy to scan.

## Live Demo
- GitHub Pages: `https://your-username.github.io/simple-resume-website/`
- Repository: `https://github.com/your-username/simple-resume-website`

## Objective
Practise organising structured information with semantic HTML and styling it with CSS.

## Features
- Two-column layout built with CSS Grid (sidebar and main content)
- Semantic structure: `aside`, `main`, `section`, `article`, `address`, `time`
- Flexbox for entry headers and skill tags
- Responsive: stacks into one column below 800px
- Print stylesheet, so the page can be saved as a PDF resume (Ctrl+P)
- Accessible: heading hierarchy, labelled sections, alt text, visible focus states

## Tech Stack
| Technology | Purpose |
|---|---|
| HTML5 | Semantic structure |
| CSS3 | Grid, Flexbox, variables, media queries, print styles |
| Google Fonts | Sora and Inter |

## How to Run
1. Clone: `git clone https://github.com/your-username/simple-resume-website.git`
2. Add your photo as `images/profile.jpg`
3. Open `index.html` in a browser (or use VS Code Live Server)

## Customisation
Edit the text and links in `index.html`. Colours and fonts are set by the variables at the top of `style.css`.

## Learning Outcomes
- Choosing semantic elements to describe content correctly
- Deciding between Flexbox (one-dimensional) and Grid (two-dimensional)
- Improving readability with spacing, hierarchy and consistent typography
- Writing responsive and print-ready CSS
