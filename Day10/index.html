Frequently Asked Questions

Web development basics in ten short answers. Select a question to expand or collapse it.

  • HTML (HyperText Markup Language) is the standard language for structuring web pages. It uses elements such as headings, paragraphs, lists, links and images to describe the content of a page.

  • HTML provides the structure and content, CSS controls the appearance (colours, spacing, layout), and JavaScript adds behaviour and interactivity. Together they form the core of front-end development.

  • Semantic HTML uses elements that describe their meaning, such as header, nav, main, article and footer, instead of generic div elements. It improves accessibility, helps search engines understand the page and makes code easier to maintain.

  • Every element is a rectangular box made of content, padding, border and margin. Understanding the box model is essential for controlling spacing and sizing; box-sizing: border-box makes widths include padding and border.

  • Use Flexbox for one-dimensional layouts, such as a row of buttons or a navigation bar. Use CSS Grid for two-dimensional layouts that control rows and columns together, such as a page layout or an image gallery.

  • The Document Object Model is the browser's tree-like representation of an HTML page. JavaScript uses it to select elements, change their content, styles and classes, and respond to user events.

  • let and const are block-scoped, while var is function-scoped. Use const by default for values that are not reassigned and let for values that change; var is mostly avoided in modern code.

  • A responsive website adapts its layout to the screen size, from phones to large monitors. It relies on flexible layouts, relative units, images that scale and CSS media queries.

  • Git is a version control system that records the history of your code. It lets you undo mistakes, work on features in branches and collaborate with others, and GitHub hosts Git repositories online.

  • Accessibility ensures that people with disabilities, including those using screen readers or keyboards only, can use a website. It also improves usability and search ranking for everyone, so use semantic elements, alt text, sufficient contrast and visible focus states.
