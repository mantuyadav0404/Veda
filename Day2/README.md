# Personal Introduction Page

**Veda Technology Internship | Level 1 | Task 2 | Web Development Track**

A single-page personal introduction website built with semantic HTML5 and CSS3. It presents my name, profile image, introduction, skills, hobbies and contact details in a clean, responsive layout.

## Live Demo
- GitHub Pages: `https://your-username.github.io/personal-introduction-page/`
- Repository: `https://github.com/your-username/personal-introduction-page`

## Objective
Practise basic HTML elements, CSS selectors, spacing, colours and simple page layout.

## Features
- Sticky navigation with smooth scrolling
- Hero section with profile image and call-to-action
- About, Skills, Hobbies and Contact sections
- Fully responsive (desktop, tablet, mobile)
- Accessible: semantic landmarks, alt text, visible focus states, reduced-motion support
- Content (HTML) kept separate from presentation (CSS)

## Tech Stack
| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantics |
| CSS3 | Styling, Flexbox, Grid, CSS variables, media queries |
| Google Fonts | Sora and Inter typefaces |

## How to Run
1. Clone the repository: `git clone https://github.com/your-username/personal-introduction-page.git`
2. Add your photo as `images/profile.jpg`
3. Open `index.html` in any modern browser (or use VS Code Live Server)

## Customisation
Update the name, email, LinkedIn and GitHub links in `index.html`. Colours and fonts are controlled by the variables at the top of `style.css`.

## Learning Outcomes
- Using headings, paragraphs, lists and semantic tags correctly
- Working with class selectors, descendant selectors and pseudo-classes
- Understanding specificity and the box model
- Building responsive layouts with Flexbox, Grid and media queries
