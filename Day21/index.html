A demo page for a responsive navbar. Resize the window below 769 px, or open this page on a phone, to see the links fold into a slide-in menu.

See how it works

What this navbar does

Horizontal on desktop

Brand on the left, links and a call-to-action on the right, using Flexbox.

Slide-in on mobile

Below 769 px a hamburger button opens a panel that slides in from the right, with a dimmed overlay.

Accessible

Keyboard friendly, Esc to close, focus kept inside the open menu, and screen reader labels that update.

About this project

The menu is opened and closed by toggling one class on the header. All movement comes from CSS transitions, so the JavaScript only changes state and never touches styles directly.

Try it: open the menu, press Esc, tap the dark overlay, or choose a link. Each one closes the menu.
