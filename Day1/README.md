# Tribute Page – Dr. A. P. J. Abdul Kalam

## 📌 Project Overview

This project is a responsive single-page tribute website dedicated to **Dr. A. P. J. Abdul Kalam**, an Indian aerospace scientist and the 11th President of India.

The project was developed as **Task 1 of my Web Development Internship** to practice semantic HTML, CSS styling, page structure, and responsive web design.

## 🎯 Objective

The objective of this task was to build a clean and responsive tribute page using HTML5 and CSS3 while applying fundamental web development concepts.

## ✨ Features

- Dedicated tribute page for Dr. A. P. J. Abdul Kalam
- Biography section
- Achievements section
- Life timeline
- Image with caption
- Semantic HTML structure
- Clean and readable layout
- Responsive design for desktop and mobile screens
- Mobile media query

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Media Queries
- Responsive Web Design

## 🧩 HTML Concepts Used

The project uses semantic HTML elements including:

- `<header>`
- `<main>`
- `<section>`
- `<figure>`
- `<figcaption>`
- `<footer>`
- Headings, paragraphs, lists, and images

## 🎨 CSS Concepts Used

- Box Model
- Margins and Padding
- `max-width`
- Flexbox
- Borders and Border Radius
- Box Shadows
- Pseudo-elements
- Responsive Media Queries
- Basic Typography and Layout Styling
